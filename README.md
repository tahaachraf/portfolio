# Portfolio de Taha Achraf Fadhloune

Version React autonome du portfolio. Le portrait, les icônes et les styles sont servis depuis ce dossier ; aucun compte, serveur backend, CDN ou ressource distante n'est requis pour lancer le site. Les liens vers GitHub, LinkedIn et les coordonnées sont conservés.

Le site propose les langues français et anglais ainsi que les thèmes clair et sombre. Chaque préférence est mémorisée dans le navigateur.

## Prérequis

- Node.js 20.19 ou plus récent
- npm

## Lancer en local

```bash
npm install
npm run dev
```

## Construire et prévisualiser la version de production

```bash
npm run build
npm run preview
```

Le build statique est généré dans `dist/public/`.
